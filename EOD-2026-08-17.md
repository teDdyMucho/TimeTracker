## 1. Mobile — "stay signed in" / profile-reset bug FIXED ✅
- Client report: *"kapag hindi ko po nalog out, nagiging ganito the next day"* → app showed **"Welcome back, there"**, a **"T" avatar**, and **0h**.
- **Root cause:** on the overnight token refresh, `onAuthStateChange` called `fetchProfile()` and set `profile` to whatever it returned — if that refetch failed (slow morning network), it wrote `profile = null` even though the session was still valid. The user looked logged out.
- **Fix:** on token refresh, keep the existing profile if the refetch fails (only replace on success); never wipe on failure. Added a home-screen safety net that refetches the profile when a session exists but the profile is missing. Files: `mobile/store/auth.ts`, `mobile/app/(app)/index.tsx`.
