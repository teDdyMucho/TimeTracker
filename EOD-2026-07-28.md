Workers needed an easy way to install without admin logins.

- Enlarged the Timevera logo on the `/install` page (was too small).

## 3. APK hosting — fixed the failed Netlify deploy ✅
- **Root cause found:** the 78MB `Timevera.apk` was committed to git **twice** (admin/public + mobile), which **blocked the Netlify deploy** — that's why the "Get the App" tab wasn't showing on the live site.
- **Fix:** untracked both APKs from git, added `*.apk`/`*.aab`/`*.ipa` to `.gitignore`, and now host the Android APK on **Google Drive** (Supabase Storage was too small at 50MB).
- Verified the Google Drive **direct-download** link works (returns the APK, filename `Timevera.apk`, 78MB, skips the virus-scan interstitial via `drive.usercontent.google.com`).
- The Android "Download APK" button + copy-link now point to that Drive URL.

## 4. Mobile APK — confirmed no rebuild needed
- Verified in code + git: **messaging and auto clock-out are already in the last APK** (`3a6ddc5`). The only newer commits were admin-only (password reset), which don't affect the mobile app — so no new mobile build was required.
