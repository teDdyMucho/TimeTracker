## 2. Xero push — two bugs fixed, then VERIFIED ✅
- **Bug A — `invalid_scope`:** the token request was sending an explicit `scope` param. For a Custom Connection the scopes are fixed at authorisation and come back with the token; passing them = rejection. **Fix:** `getCustomConnectionToken` no longer sends `scope`.
