## 2. Admin — built today ✅
- **Supervisor role (PRD §4).** Employees → Supervisor field. Supervisors sign in to the dashboard and see only Overtime, Attendance and Leave for their own team; cannot add/edit times; admin pages and API routes redirect them away. Approvals record who decided.
- **Entities → Pay settings.** Ordinary hours, OT tier 1 / 2, Saturday, Sunday, public-holiday multipliers, and an **"Overtime must be approved" switch — off by default** so current pay figures are unchanged until the client decides.
- **One labour-cost engine** (`admin/lib/labour-cost.ts`) now feeds payroll, Xero push, project totals, reports and dashboard, so every page reconciles.
- **Public Holidays page** and **Settings page** (pay cycle, labour-cost alert threshold).
- **Projects:** edit form, budget hours / labour cost, start and end dates, actual hours and cost with budget bars.
- **Dashboard:** Labour Cost This Week, Overtime Cost, Payroll Due cards; Labour Cost Summary by project / employee / business / location; Realtime refresh; admin notification bell (payroll ready, Xero failed, budget threshold, missing timesheets).
- **Reports:** labour cost by project with budget variance, by employee, business entity, site vs factory with cost, overtime report by tier, project filter, CSV on every table.
- **Payroll:** Draft → Reviewed → Approved → Exported, per-employee allowances, default period from the pay cycle.
- **Xero:** push now writes `xero_sync_status` (pending / success / failed), marks the run Exported, alerts admins on failure. The old code checked for a value (`synced`) that does not exist, so Recalculate / Delete were never locked after a push.
- **Migration 0028** (not yet applied): pay-config flag, Realtime publication, audit-log triggers, 5 PM Melbourne missing-timesheet reminder, RLS guards so employees cannot self-approve timesheets, attendance or leave.
