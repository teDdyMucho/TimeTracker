ARKO Joinery still needs its own Xero invite

A Xero Custom Connection links to one organisation only. Build One is connected and working. To run the same integration for ARKO Joinery Pty Ltd, we need a separate connection authorised on ARKO's Xero org — same one-time step Chris did for Build One.

  1. Someone with admin access to ARKO Joinery's Xero receives and accepts the Custom Connection invite.
  2. They approve the four scopes below (identical to Build One's).
  3. Xero issues a Client Secret for ARKO, which we add to the app — and ARKO's push works exactly like Build One's.
payroll.employees  — read employees, write leave
payroll.timesheets  — write worked hours
payroll.settings.read  — read rates, leave types, calendar
accounting.settings.read  — read job tracking
